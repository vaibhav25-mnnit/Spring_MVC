# Spring_MVC

**This repository contains a Java web application using the Spring MVC framework for learning and hands-on practice.**  
It demonstrates core concepts of Spring MVC including controllers, views, models, HTTP routing, and request handling.

---

## 📌 About

This project is designed for understanding how **Spring MVC (Model-View-Controller)** applications work.  
Spring MVC is a powerful Java framework that follows the **MVC design pattern** to build scalable web applications and dynamic server-side pages.:contentReference[oaicite:0]{index=0}

You will find example controllers, view templates (JSP/HTML), and routing logic that show how requests are handled from the browser to the server and back.

---

## 🚀 Features

- 🔹 Uses **Spring MVC framework**  
- 🔹 Demonstrates request handling with `@Controller`  
- 🔹 Uses dynamic view rendering  
- 🔹 Structured according to MVC principles  
- 🔹 Good starter project for beginners in Java web development
